# Image Annotation Project: Cars, Dogs and Cats

A hands-on image labelling project completed with **CVAT** (Computer Vision Annotation Tool). I labelled images of **cars, dogs and cats** to practise producing clean, consistent, high-quality training data for computer vision and AI models.

## Overview

| Item | Details |
|---|---|
| Tool | CVAT (app.cvat.ai) |
| Labels | `car`, `dog`, `cat` |
| Annotation type | Bounding boxes |
| Number of images | 34 |
| Number of annotations | 34 |
| Export format | COCO 1.0 |

## What I Did

1. Created a CVAT project and defined the three labels: car, dog and cat.
2. Uploaded a set of images as an annotation task.
3. Drew bounding boxes tightly around each object and assigned the correct label.
4. Reviewed every image to check for missed objects, wrong labels and loose boxes.
5. Exported the annotations in **COCO 1.0** format, a standard format used to train object detection models.

## Annotation Guidelines I Followed

- Draw each box tightly around the visible object, with no extra background.
- Label every visible car, dog and cat in the image, including partly hidden ones.
- Use one label per object and keep naming consistent across the whole dataset.
- Skip objects that are too small or blurry to identify with confidence.
- Re-check each image before finishing the task.
